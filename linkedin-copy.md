## 1. Headline

The 220-character line under your name. Highest-leverage text on the profile:
it shows in every search result, every comment you leave, every DM preview.

**Use this one:**

```
Software Engineer & DevOps Lead @ ZeezTech | TypeScript · React · Next.js · Node.js · PostgreSQL | I build web applications and run the infrastructure they live on
```

*(162 characters.)*

**Why lead with DevOps Lead rather than hiding it.** Your instinct was a plain
"Software Engineer" headline, and I'd push back on that one point. "DevOps
Lead" is rarer than "Software Engineer," it's a *lead* title, and it is the
single thing that separates you from every other full-stack candidate — you
can point at an EC2 box running nginx and PM2 that you personally keep alive.
Thousands of people can build a React app. Far fewer can deploy it and keep it
up. Pairing the two says "engineer who owns the whole path," which is a
stronger claim than either half alone.

It also has to appear in Experience regardless — that's your actual title, and
a title that doesn't match a reference check is a real problem. Better to make
it an asset than a footnote.

**If you'd rather keep it purely engineer-forward:**

```
Software Engineer | Full-Stack Web Applications | TypeScript · React · Next.js · Node.js · PostgreSQL · AWS | Building and deploying production systems
```

**Rules if you write your own:** lead with "Software Engineer," never open with
"Freelance." Name 4–5 technologies maximum, and only ones you could be
interviewed on for ten minutes — so no NestJS until you've shipped with it.
Skip "passionate," "aspiring," and "| Open to work" (the private recruiter
setting does that job without spending headline characters).
